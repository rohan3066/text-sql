# Text-to-SQL AI — E-commerce Database Analytics Assistant

A comprehensive, production-ready AI analytics platform that enables business users to query a MySQL database using natural language. Built with FastAPI, React, Tailwind CSS, MySQL, and powered by Gemini.

## Features

- **Natural Language to SQL**: Talk to your data using English. Powered by Gemini 1.5 Pro.
- **Robust SQL Validation & Security**: All AI-generated SQL goes through an aggressive security layer using `sqlglot`. It enforces read-only `SELECT` operations and validates against the database schema.
- **SQL Editor & Execution**: A Monaco-based SQL editor for technical users.
- **Automated Data Visualization**: AI automatically recommends and renders the best charts (Recharts) for your query results.
- **Query History & Saved Queries**: Keep track of previous queries, with execution times and statuses.
- **SQL Auto-Correction**: Automatically detects execution errors and loops back to Gemini for syntax repair.
- **SQL Optimization**: Provides index recommendations and complexity scoring for queries.
- **Responsive Dashboard**: Dark-mode themed interface built with React, Tailwind CSS, and Vite.

## Architecture

1. **Frontend**: React (Vite), Tailwind CSS, Recharts, Monaco Editor.
2. **Backend**: FastAPI, SQLAlchemy (ORM), SQLGlot (Validation), PyJWT.
3. **Database**: MySQL 8.0, with dual connection pools (Admin for history/users, ReadOnly for query execution).
4. **AI Engine**: Google Gemini API via `google-generativeai`.

## Getting Started

### 1. Prerequisites
- Docker & Docker Compose
- A Gemini API Key from Google AI Studio.

### 2. Environment Variables

Create `.env` files in both the frontend and backend directories. You can copy the provided `.env.example` files:

**`backend/.env`**
```env
# Database configuration
MYSQL_USER=admin
MYSQL_PASSWORD=adminpassword
MYSQL_ROOT_PASSWORD=rootpassword
MYSQL_DATABASE=ecommerce
MYSQL_HOST=db
MYSQL_PORT=3306

# Read-only user
MYSQL_READONLY_USER=readonly
MYSQL_READONLY_PASSWORD=readonlypassword

# API Settings
SECRET_KEY=supersecretkey-change-me-in-production
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=1440

# AI Configuration
GEMINI_API_KEY=your_gemini_api_key_here
```

**`frontend/.env`**
```env
VITE_API_URL=http://localhost:8000/api
```

### 3. Run with Docker Compose

Build and start the full application stack (MySQL, FastAPI, React via Nginx):

```bash
docker-compose up --build
```

The database container will automatically run the schema and seed scripts on initialization. This populates a realistic e-commerce database with ~500 orders.

### 4. Access the Application

- **Frontend**: http://localhost:3000
- **API Docs (Swagger UI)**: http://localhost:8000/docs
- **Default Login**: Username: `admin`, Password: `adminpassword`

## Security Considerations

1. **Read-Only Database Role**: The application connects to MySQL via two separate users. All dynamic queries generated by users/AI are executed strictly through the `readonly` MySQL user, which does not have INSERT/UPDATE/DELETE/DROP privileges.
2. **AST Parsing (SQLGlot)**: Before any SQL touches the database, it is parsed by `sqlglot`. We reject multiple statements and ensure the root AST node is a `SELECT` statement.
3. **Strict Table References**: The parser checks every table referenced in the generated query against the application schema, rejecting any attempts to query system tables (like `information_schema` or `mysql.user`).

## Development

- **Run Backend Locally**:
  ```bash
  cd backend
  python -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  uvicorn app.main:app --reload
  ```
- **Run Frontend Locally**:
  ```bash
  cd frontend
  npm install
  npm run dev
  ```
- **Run Tests**:
  ```bash
  cd backend
  pytest
  ```
